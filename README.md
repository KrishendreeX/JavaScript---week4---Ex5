# JavaScript - Template Literals and Arrow Functions

## Overview
This project is a practical exercise focused on mastering modern JavaScript (ES6+) syntax features. The goal of the assignment is to replace older, verbose coding styles with clean, readable, and maintainable alternatives—specifically **Template Literals** and **Arrow Functions**.

## Project Structure
* **File Name:** `temp_lits_arrow_funct.js`
* **Concepts Covered:** String Interpolation, Multiline Strings, Arrow Functions, Implicit Returns, and Array Methods (`.filter()`, `.map()`).

  
## Technical Requirements Completed

### 1. Multiline String Generation
Demonstrates how template literals (using backticks `` ` ``) eliminate the need for traditional newline characters (`\n`), allowing strings to naturally span multiple lines in the source code.

### 2. Dynamic HTML Templating
Features a functional component (`CreateProductCard`) that utilizes string interpolation (`${variable}`) to cleanly inject dynamic data into an HTML structural block.

### 3. Arrow Function Conversion
Showcases the transition from standard function declarations to concise ES6 arrow functions (`=>`), demonstrating how to simplify logic and maintain clear scope.

### 4. High-Order Array Methods
Combines arrow functions with native JavaScript array methods:
* **`.filter()`**: Extracts elements from an array based on a specific conditional criteria (e.g., finding even numbers).
* **`.map()`**: Traverses an array to transform each individual element (e.g., squaring a dataset).
